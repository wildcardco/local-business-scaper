# Logo Usage Examples

## Correct Usage Examples

### 1. Primary Logo on Dark Background
**File**: `WCLogo.png` (white version)
**Background**: Dark burgundy (#2d1818, #3a1818, #4a1c1c)
**Usage**: Website headers, dark presentations, business cards with dark backgrounds

### 2. Logo with Background
**File**: `WCLogoWBackground.png`
**Usage**: Social media profiles, email signatures, documents where background is needed

### 3. Emblem Only
**File**: `WCEmblem.png`
**Usage**: Favicons, app icons, small spaces where full logo won't fit, watermarks

### 4. Spade Symbol
**File**: `WCSpade.png`
**Usage**: Decorative elements, pattern creation, minimal branding applications

### 5. Typography Only
**File**: `WCType.png`
**Usage**: When symbol/emblem is used separately, text-heavy applications

## Size Guidelines

### Minimum Sizes
- **Full Logo**: 120px wide (digital), 1 inch wide (print)
- **Emblem Only**: 32px x 32px (digital), 0.25 inch (print)
- **Spade Symbol**: 16px x 16px minimum

### Recommended Sizes
- **Website Header**: 200-300px wide
- **Business Card**: 2-3 inches wide
- **Letterhead**: 2.5-4 inches wide
- **Social Media Profile**: 400x400px (emblem), 1200x630px (full logo with background)

## Clear Space Requirements

Maintain clear space around the logo equal to the height of the spade symbol in the emblem.


## Background Guidelines

### Approved Backgrounds
- **Solid Colors**: White, light grays, brand burgundy colors
- **Subtle Textures**: Low-contrast, non-competing patterns
- **Photography**: High contrast areas, with overlay if needed

### Avoid These Backgrounds
- **Busy Patterns**: Competing visual elements
- **Low Contrast**: Insufficient contrast between logo and background
- **Bright Colors**: Colors that compete with brand palette
- **Complex Photography**: Without proper contrast or overlay

## Color Variations

### On Dark Backgrounds
Use white logo versions for maximum contrast and readability.

### On Light Backgrounds
Use dark burgundy logo versions or the version with background.

### Monochrome Applications
- **Black on White**: For single-color printing
- **White on Black**: For reverse applications
- **Single Brand Color**: When limited to one color

## File Format Guidelines

### Digital Applications
- **PNG**: Websites, presentations, digital documents
- **SVG**: Scalable web applications (when available)
- **JPG**: When transparency not needed

### Print Applications
- **PNG**: High resolution (300 DPI minimum)
- **EPS**: Vector format for professional printing (when available)
- **PDF**: Document embedding

## Common Mistakes to Avoid

### ❌ Don't Do This:
1. **Stretch or Distort**: Never change proportions
2. **Add Effects**: No shadows, glows, or 3D effects
3. **Change Colors**: Stick to approved brand colors
4. **Recreate**: Always use official files
5. **Low Resolution**: Use appropriate resolution for application
6. **Poor Contrast**: Ensure logo is clearly visible
7. **Crowded Placement**: Respect clear space requirements

### ✅ Do This Instead:
1. **Maintain Proportions**: Keep original aspect ratio
2. **Use Clean Applications**: Simple, professional presentation
3. **Follow Brand Colors**: Use approved color variations
4. **Use Official Files**: Download from brand assets folder
5. **Appropriate Resolution**: 72 DPI web, 300 DPI print
6. **High Contrast**: Ensure excellent readability
7. **Proper Spacing**: Maintain required clear space
