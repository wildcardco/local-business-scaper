# Wild Card Creative Co. Brand Assets

This folder contains all official brand assets for Wild Card Creative Co.

## Folder Structure

### `/logos/`
Contains all logo variations and brand symbols:
- `WCLogo.png` - Full logo with text
- `WCLogoWBackground.png` - Logo with background
- `WCEmblem.png` - Emblem/symbol only
- `WCSpade.png` - Spade symbol only
- `WCType.png` - Typography/text only

### `/marketing/`
Contains marketing materials and promotional assets:
- `Wild Card FB Banner 2025(1).png` - Facebook cover banner

### `/documentation/`
Contains brand guidelines and usage documentation:
- `Wild-Card-Creative-Brand-Guide.md` - Complete brand guide

## Usage Guidelines

Please refer to the brand guide in `/documentation/` for proper usage guidelines, color specifications, and typography information.

## File Formats

All logo files are provided in PNG format with transparent backgrounds where applicable. For vector formats (SVG, EPS) or other specifications, please contact the Wild Card Creative Co. team.
