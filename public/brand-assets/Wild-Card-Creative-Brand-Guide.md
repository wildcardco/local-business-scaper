## Color Palette

### Primary Colors

#### Deep Burgundy/Maroon
- **Hex**: `#2d1818`
- **RGB**: rgb(45, 24, 24)
- **Usage**: Primary background, main brand color
- **Represents**: Sophistication, reliability, premium quality

#### Rich Burgundy
- **Hex**: `#3a1818`
- **RGB**: rgb(58, 24, 24)
- **Usage**: Secondary background, section dividers
- **Represents**: Warmth, creativity, passion

#### Warm Burgundy
- **Hex**: `#4a1c1c`
- **RGB**: rgb(74, 28, 28)
- **Usage**: Accent backgrounds, hover states
- **Represents**: Energy, innovation, forward-thinking

### Secondary Colors

#### Pure White
- **Hex**: `#ffffff`
- **RGB**: rgb(255, 255, 255)
- **Usage**: Primary text, logo backgrounds, clean contrast
- **Represents**: Clarity, professionalism, simplicity

#### Soft White (70% opacity)
- **Hex**: `#ffffff` at 70% opacity
- **Usage**: Secondary text, subtle elements
- **Represents**: Approachability, readability

### Color Psychology
The burgundy/maroon color scheme conveys:
- **Trust & Reliability**: Deep, stable colors inspire confidence
- **Sophistication**: Premium, high-end appearance
- **Creativity**: Rich, warm tones suggest artistic capability
- **Professionalism**: Serious, business-focused approach

## Typography

### Primary Font Family
**ITC Avant Garde Gothic Pro**

### Font Weights Available
- **Regular** (400): Body text, general content
- **Medium** (500): Subheadings, emphasis
- **Bold** (700): Headings, strong emphasis

### Typography Hierarchy
- **H1 Headings**: ITC Avant Garde Gothic Pro Bold, 4xl (36px+)
- **H2 Headings**: ITC Avant Garde Gothic Pro Bold, 3xl (30px)
- **H3 Headings**: ITC Avant Garde Gothic Pro Medium, 2xl (24px)
- **Body Text**: ITC Avant Garde Gothic Pro Regular, base (16px)
- **Small Text**: ITC Avant Garde Gothic Pro Regular, sm (14px)

### Font Characteristics
- **Modern**: Clean, contemporary geometric design
- **Professional**: Business-appropriate and readable
- **Distinctive**: Unique character that stands out
- **Versatile**: Works well in digital and print applications

### Fallback Fonts

## Logo Usage Guidelines

### Proper Usage

#### Clear Space
- Maintain minimum clear space equal to the height of the spade symbol around all logo applications
- Never place other elements within this clear space

#### Minimum Size
- **Digital**: 120px wide minimum
- **Print**: 1 inch wide minimum
- **Favicon**: 32px x 32px (use emblem only)

#### Preferred Backgrounds
- **Primary**: Dark backgrounds (burgundy variations)
- **Secondary**: White or light neutral backgrounds
- **Avoid**: Busy patterns, competing colors, low contrast situations

### Incorrect Usage

#### Don't:
- Stretch, distort, or alter proportions
- Change colors outside brand palette
- Add effects, shadows, or outlines
- Place on backgrounds with insufficient contrast
- Use outdated or low-resolution versions
- Recreate or modify logo elements

#### Color Variations
- **On Dark Backgrounds**: Use white logo
- **On Light Backgrounds**: Use dark burgundy logo
- **Monochrome**: White on dark, dark on light

## Digital Applications

### Website Design Principles

#### Layout & Structure
- **Clean, modern layouts** with plenty of white space
- **Grid-based design** for consistency and organization
- **Mobile-first approach** ensuring responsive design
- **Intuitive navigation** with clear hierarchy

#### Visual Elements
- **Consistent color usage** following brand palette
- **Typography hierarchy** using ITC Avant Garde Gothic Pro
- **Strategic use of imagery** supporting brand message
- **Subtle animations** enhancing user experience

#### User Experience
- **Fast loading times** for optimal performance
- **Accessible design** following WCAG guidelines
- **Clear calls-to-action** guiding user behavior
- **Professional presentation** reflecting brand quality

### Social Media Guidelines

#### Profile Images
- Use **WC Emblem** for profile pictures
- Ensure **high contrast** against platform backgrounds
- Maintain **consistent sizing** across platforms

#### Cover Images/Banners
- Use **Wild Card FB Banner 2025** as template
- Include **company name and tagline**
- Maintain **brand colors and typography**

#### Content Style
- **Professional photography** when possible
- **Consistent color scheme** in graphics
- **Brand typography** in text overlays
- **Logo placement** when appropriate

### File Formats & Specifications

#### Logo Formats
- **PNG**: For web use, transparent backgrounds
- **SVG**: Vector format for scalability (recommended for web)
- **EPS**: Vector format for print applications
- **JPG**: For backgrounds or when transparency not needed

#### Resolution Guidelines
- **Web**: 72 DPI minimum, optimized file sizes
- **Print**: 300 DPI minimum, high quality
- **Large Format**: Vector formats preferred

### Usage Rights & Guidelines

#### Internal Use
- All brand assets available for company use
- Maintain file organization and naming conventions
- Use most current versions of all assets

#### External Use
- Provide brand guidelines to partners/vendors
- Approve all external usage of brand assets
- Ensure compliance with usage guidelines

#### Quality Control
- Regular audits of brand asset usage
- Update assets as brand evolves
- Maintain consistent application across all touchpoints
